List of scripts

# compute_PA2.py
Computes average PA for scenarios described in Baronchelli et al. 2026, Table 2

# Rayleigh_test8.py
Computes alignment significance using circular statistics methods (Rayleigh test), for the various scenarios considered in Baronchelli et al. (2026). Results reported in Table 3 therein

# MC_sim6.py
Tests the validity of the binomial approach (Section 7, Equations 2 and 5 in Baronchelli et al. 2026) with a series of MC simulations. Results are listed in Table D.1, to be compared with those reported in Table 2

# compute_probabilities2.py
Used to compute the significance of the alignments once the uncertainties are included in the computation (using MC simulations)
